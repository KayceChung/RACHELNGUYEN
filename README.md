# Nguyen Thi Thao Nhi — Operations Portfolio

Online portfolio built with React, Vite, Tailwind CSS v4, and Framer Motion.

## Development

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
npm run preview  # preview the production build locally
```

## Structure

- `src/data.js` — all page content (metrics, projects, timeline, capabilities, awards)
- `src/motion.js` — shared Framer Motion easing/variants
- `src/components/` — one component per section
