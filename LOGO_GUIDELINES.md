# Rachel Nguyễn - Luxury Personal Branding Logo

## 🎨 Logo Design System

### Design Philosophy
The logo system for Rachel Nguyễn embodies **sophisticated elegance** meets **premium travel expertise**. Inspired by the golden hour of travel—that perfect moment when destinations reveal their magic—the design communicates trust, warmth, and international professionalism.

---

## 📐 Logo Variants

### 1. **Primary Logo — Signature Style**
- **Usage:** Website header, presentations, email signature, official documents
- **Elements:**
  - Elegant compass rose symbol (representing travel & navigation)
  - "Rachel Nguyễn" in refined serif typography
  - "Travel Consultant" subtitle in clean sans-serif
- **Dimensions:** Ideal width 200-300px for digital applications
- **File:** `Logo.tsx` with `variant="signature"` (default)

### 2. **Secondary Logo — RN Monogram**
- **Usage:** Social media profile pictures, favicon, app icons, watermarks
- **Elements:**
  - Circular refined geometry frame
  - Elegant R and N letterforms with serif styling
  - Minimal compass accent point
- **Dimensions:** 48x48px minimum, scalable to 256x256px
- **File:** `Logo.tsx` with `variant="monogram"`

### 3. **Compact Logo**
- **Usage:** Mobile navigation, tight spaces, badges
- **Elements:**
  - Simplified compass icon
  - "Rachel" wordmark only
- **File:** `LogoCompact` component

## 📏 Logo Clear Space & Sizing

### Minimum Clear Space
- Equal to the height of the compass symbol in signature logo
- Approximately 0.5x logo height on all sides

### Minimum Sizes
- **Signature Logo:** 100px width (digital), 25mm (print)
- **Monogram Logo:** 24px width (digital), 8mm (print)
- **Compact Logo:** 80px width (digital), 20mm (print)

### Recommended Sizes
- **Website Header:** 180-220px width
- **Business Card:** 40-50mm width
- **Social Media Profile:** 400x400px (monogram)
- **Email Signature:** 150px width

## ✅ Usage Guidelines

### DO:
✓ Use signature logo for primary brand touchpoints  
✓ Use monogram for social media and compact spaces  
✓ Maintain proper clear space around logo  
✓ Use approved color variations only  
✓ Ensure logo legibility at all sizes  
✓ Place on clean, uncluttered backgrounds  
✓ Use high-resolution files for print (300 DPI minimum)  

### DON'T:
✗ Don't stretch, squeeze, or distort logo proportions  
✗ Don't use colors outside the approved palette  
✗ Don't add effects (shadows, glows, gradients) to logo  
✗ Don't place on busy or low-contrast backgrounds  
✗ Don't rotate or flip the logo  
✗ Don't separate logo elements  
✗ Don't use outdated versions
